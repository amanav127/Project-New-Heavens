# Project: New Heavens — Space Shuttle Design

A multi-part space shuttle assembly designed and modeled in Onshape. This repository contains the reference documentation, structural specifications, and CAD data for the **Project: New Heavens** spacecraft model.

## Assembly Overview & Breakdown

The main assembly (`Assembly 1`) integrates the primary orbiter body, dual side boosters, and engine propulsion nozzles.

### Sub-Components & Instances (5 Total)
| Component | Quantity | Description / Role |
| :--- | :---: | :--- |
| **Assembly 1 Origin** | 1 | Main assembly reference plane and coordinate system |
| **Part 1** | 2 | Side Boosters / Auxiliary fuel tanks attached to fuselage |
| **Part 2** | 2 | Wing structures / Main aerodynamic surfaces |
| **Part 3** | 1 | Primary Orbiter Fuselage and Cockpit section |

### Mate Features & Kinematics (4 Total)
- **Planar 1**: Aligns the planar reference surfaces of the dual boosters along the central fuselage body.
- **Fastened 1**: Locks the primary orbiter fuselage (Part 3) to the central assembly origin.
- **Fastened 2**: Secures the starboard wing and booster assembly to the main fuselage structure.
- **Fastened 3**: Secures the port wing and booster assembly to the main fuselage structure.
